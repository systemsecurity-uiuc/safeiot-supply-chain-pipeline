# JBomAudit

**Status: reserved — integration pending.** This directory is a placeholder for JBomAudit; setup and usage instructions will be filled in once the tool is wired into this pipeline.

JBomAudit evaluates the completeness and accuracy of Java SBOMs (Software Bill of Materials) by cross-checking them against their corresponding JAR files, categorizing discrepancies as missing or incorrect dependencies.

- Paper: Yue Xiao, Dhilung Kirat, Douglas Lee Schales, Jiyong Jang, Luyi Xing, Xiaojing Liao. *JBomAudit: Assessing the Landscape, Compliance, and Security Implications of Java SBOMs.* NDSS 2025.
- Upstream repository: https://github.com/code-genome/jbomaudit
