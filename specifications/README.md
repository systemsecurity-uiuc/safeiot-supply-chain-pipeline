# SBOM / CBOM / AI-BOM Specifications

This directory contains static specification documents and format references for Bill-of-Materials standards relevant to IoT supply-chain verification. The current focus is on **Software Bills of Materials (SBOM)**, with planned expansion to **Cryptographic Bills of Materials (CBOM)** and **AI Bills of Materials (AI-BOM)**.

> **Note:** These files are manually maintained due to access restrictions on upstream sources. When new specification versions are released, update the relevant subdirectory by hand and commit the changes.

---

## SBOM

The primary focus of the supply-chain pipeline's current verification efforts. Formats in scope include CycloneDX and SPDX.
